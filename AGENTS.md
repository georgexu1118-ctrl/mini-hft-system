# Agent Entry Point

This repository supports multiple AI development agents with separate context
surfaces:

- Codex: read `.codex/AGENTS.md`.
- Claude Code: read `CLAUDE.md`; `.claude/` is reserved for Claude-specific
  workspace configuration.

The canonical project architecture, performance constraints, and Codex workflow
live in `.codex/AGENTS.md`. Keep this root file short so instructions are not
duplicated across agents.
