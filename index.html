Design Principles

The hot-path contract.

The engine boundary enforces a zero-I/O invariant. No FastAPI, no SQLAlchemy, no asyncio — pure computation behind a single protocol that Python, C++, and FPGA all implement identically.

engine/hal/abstract.py — replaceable matching contract 
# Python, C++, and FPGA all implement this.
# OrderService never sees a concrete engine.
class MatchingHAL(Protocol):
    def submit_order(
        self, order: Order
    ) -> MatchResult: ...

    def cancel_order(
        self, order_id: str
    ) -> Order | None: ...

    def get_snapshot(
        self, symbol: str
    ) -> BookSnapshot | None: ...
shared/events.py — non-blocking fan-out 
# publish_nowait: ~100ns.
# Never blocks the matching hot path.
# DB and WS push drain independently.
class EventBus:
    def publish_nowait(
        self, event: DomainEvent
    ) -> None:
        for q in self._queues[event.type]:
            try:
                q.put_nowait(event)
            except asyncio.QueueFull:
                # metric, not an error
                self.drop_count += 1
